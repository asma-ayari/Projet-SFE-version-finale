## 🛟 TROUBLESHOOTING

### ❌ Je vois toujours les clés littérales (COURSE_DETAIL_ID2.PAGE_2_*)

**Cause possible 1: Cache Angular**
```bash
# Solution:
rm -rf .angular/cache/
npm ci
npm start
```

**Cause possible 2: Cache navigateur incomplet**
```bash
# Utilisez une session incognito:
Ctrl+Shift+N (Chrome)
Cmd+Shift+N (Mac)
# Accédez à http://localhost:4200/formateur/cours/2/voir
```

**Cause possible 3: Fichiers pas réchargés**
```bash
# Vérifiez que les fichiers ont été modifiés:
# Sur Windows:
dir /S /B "src/assets/i18n/fr.json"
# Devrait montrer une date récente

# Sur Mac/Linux:
ls -la src/assets/i18n/fr.json
```

### ❌ Le serveur n'affiche pas "Compiled successfully"

**Action:**
```bash
# Arrêtez le serveur
Ctrl+C

# Installez les dépendances
npm ci

# Relancez
npm start
```

### ❌ Erreur: "Cannot find module"

```bash
# Réinstallez tout
rm -rf node_modules
npm ci
npm start
```

### ❌ Rien ne change après les 3 étapes

**Contacts alternates:**
1. Vérifiez que `fr.json` contient `PAGE_2_INSTRUCTION`
2. Assurez-vous que le fichier `GENERER_CLES_I18N_MANQUANTES.py` a été exécuté
3. Vérifiez que `public/i18n/fr.json` est aussi à jour

```bash
# Vérifier que la clé existe:
grep -r "PAGE_2_INSTRUCTION" src/assets/i18n/fr.json
# Doit montrer: "PAGE_2_INSTRUCTION": "Visualisez..."
```
