## 🎓 COMPRÉHENSION DE LA CONVENTION

### Format Complet
```
COURSE_DETAIL_[ID]_PAGE_[N]_[COMPOSANT]_[TYPE]

Exemple: COURSE_DETAIL_ID1_PAGE_6_TAKEAWAY_PREFIX
         └────────────┬─────────┘ └┬┘ └──────┬──┘ └────┬────┘
                      │            │         │         │
                   Cours        Page 6    Composant  Type (PREFIX)
```

### Composants
- **PAGE_N_TITLE** → Titre de la page
- **PAGE_N_NUMBER** → Numéro (ex: "Page 1/6")
- **PAGE_N_LEAD** → Texte d'introduction
- **PAGE_N_INTRO** → Contexte d'apprentissage
- **PAGE_N_ITEM_[N]** → Éléments listés
- **PAGE_N_TIPS_TITLE** → Titre des conseils
- **PAGE_N_TIP_[N]_* ** → Conseils structurés

### Types de Contenu
- **PREFIX** → Texte avant emphase
- **HIGHLIGHT** → Texte mis en valeur
- **SUFFIX** → Texte après emphase
- **TITLE** → Titres
- (autres patterns observés)
