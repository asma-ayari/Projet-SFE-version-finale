## 📞 Support et Maintenance

### En Cas de Problème

1. **Traductions manquantes?**
   - Consulter `TRANSLATION_KEYS_REFERENCE.md`
   - Vérifier dans `public/locales/[lang]/translation.json`
   - Lancer: `bash scripts/check-missing-keys.sh`

2. **RTL ne fonctionne pas?**
   - Vérifier `[dir]="language.isRTL() ? 'rtl' : 'ltr'"` dans template
   - Vérifier CSS (utiliser logical properties)
   - Consulter troubleshooting dans `README_BILINGUAL.md`

3. **Pipe translate n'affiche rien?**
   - Vérifier dans DevTools que la traduction existe
   - Si elle affiche la clé, la traduction est manquante
   - Ajouter dans les JSON files

4. **Performance lente?**
   - Vérifier taille des fichiers JSON: `du -sh public/locales/*/translation.json`
   - Vérifier dans DevTools Network tab
   - Optimiser avec compression gzip
