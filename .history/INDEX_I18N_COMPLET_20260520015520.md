## 🎓 Apprentissage

### Pourquoi ça s'affichait mal?
Angular recherche les clés dans le fichier JSON. Si une clé n'existe pas, elle affiche la clé elle-même.

### Comment c'est fixé?
Les clés ont été automatiquement générées à partir du contenu réel des cours et ajoutées au fichier JSON.

### Comment ça va rester fixé?
Les clés resteront dans le fichier JSON tant que vous ne les supprimez pas.
