## 🔄 PATTERN DE COMPOSITION

### Modèle PREFIX/HIGHLIGHT/SUFFIX

Utilisé pour les textes avec emphases:

```
PAGE_N_[COMPONENT]_PREFIX:    "Texte avant l'emphase"
PAGE_N_[COMPONENT]_HIGHLIGHT: "TEXTE EN GRAS OU COULEUR"
PAGE_N_[COMPONENT]_SUFFIX:    "Texte après l'emphase"
```

**Exemple PAGE_6_LEAD:**
```
Préfixe:      "C'est pourquoi il faut maintenir une"
Highlight:    "distance de sécurité suffisante"
Suffixe:      "avec le véhicule qui précède :"

Rendu final: "C'est pourquoi il faut maintenir une [DISTANCE DE SÉCURITÉ SUFFISANTE] avec le véhicule qui précède :"
```

### Modèle INTRO/ITEM

Utilisé pour les listes structurées:

```
PAGE_N_INTRO:    "Contexte ou titre de la liste"
PAGE_N_ITEM_1:   "Premier élément"
PAGE_N_ITEM_2:   "Deuxième élément"
PAGE_N_ITEM_3:   "Troisième élément"
...
```

## 🌍 CONSIDÉRATIONS I18N

### Pour la traduction en Arabe (ar.json)

1. **Direction du texte:** RTL (right-to-left)
2. **Longueurs de texte:** Généralement +15-20% plus long qu'en français
3. **Pluriels:** Gestion spécifique arabe (singulier, duel, pluriel)
4. **Genres:** Masculine/féminine à considérer
5. **Nombres:** Utiliser systèmes numériques arabes ou occidentaux

### Clés à tester particulièrement en arabe:
- `PAGE_N_[...]_PREFIX` + `HIGHLIGHT` + `SUFFIX`
- `PAGE_N_ITEM_[N]` (wrapping du texte)
- `PAGE_N_TITLE` (longueur des titres)
